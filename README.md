# ![Logo](chrome/app/theme/chromium/product_logo_64.png) libchromium

The **libchromium** repository is a direct fork of the GitHub **chromium**
repo, but reconfigured as a library. This is a (perpetual) work in progress,
and is in no way production or quasi-production code.

The **chromium** project's website is https://www.chromium.org, and its
GitHub source mirror is at https://github.com/chromium/chromium.
